# Portfolio demo

[portfolio-demo.CLF](portfolio-demo.CLF) is a small, editable Canvas Live architecture board. It contains six components, five relationships, one workspace area, and three labels across three layers.

1. Open Canvas Live and choose a workspace and project.
2. Import `portfolio-demo.CLF` using **Import** in the canvas library or project file panel.
3. Open the imported canvas and select **Reset view** to fit the board.
4. Open **Properties** to inspect its layers, or select and edit any component.

The example uses generic content, built-in fonts, and no external media, personal files, credentials, or AI account. AI connectivity is illustrated; importing the board does not connect an AI client.
